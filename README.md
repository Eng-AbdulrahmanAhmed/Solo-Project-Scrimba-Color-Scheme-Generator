# Color Scheme Generator

A web app that generates color schemes using [The Color API](https://www.thecolorapi.com). Pick a seed color and a scheme mode to get 5 harmonious colors.

## Features

- Color picker to choose a seed color
- Multiple scheme modes: Monochrome, Analogic, Complement, Triad, Quad, and more
- Displays 5 generated colors with their hex codes

## Built with

- HTML
- CSS
- JavaScript (Fetch API)
